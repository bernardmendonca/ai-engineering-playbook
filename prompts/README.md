# Prompts

> Reusable prompt library for engineering teams — organized by use case, tested in practice.

## How to Use

These prompts are starting points. Adapt them to your codebase, conventions, and tools. The best prompts include your specific context.

## Prompt Engineering Principles

1. **Be specific** — Include language, framework, conventions
2. **Provide context** — Reference existing code and patterns
3. **Constrain output** — Say what you don't want as much as what you want
4. **Iterate** — First output is a draft. Refine with follow-ups.
5. **Include quality requirements** — Error handling, tests, accessibility
